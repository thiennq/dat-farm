## 💡 Lessons Learned

### ✅ Thành công
- Việc đưa thêm tệp `.nojekyll` giúp GitHub Pages phục vụ các tệp tài nguyên tĩnh như `.md` trực tiếp mà không cần cấu hình phức tạp.
- Sử dụng thuộc tính `nextElementSibling` hoặc so khớp thẻ tiêu đề `H2` giúp kiểm soát tốt phạm vi gom nhóm DOM động trên Client-Side.

### 📌 Quy tắc bắt buộc mới (Mandatory Rule)
- **Luôn test local**: Trước khi tiến hành build và đẩy lên môi trường deploy (như GitHub Pages), bắt buộc phải chạy dev server cục bộ và sử dụng subagent để kiểm thử hoạt động trực tiếp nhằm phát hiện sớm các lỗi closure, CSS hoặc lỗi tải tài nguyên tĩnh.

## Phase 3: Điều hướng Timeline & Tối ưu hóa UI Di động

### Prompt / Yêu cầu
1. *Không dùng GitHub Pages để test trực tiếp nữa, bắt buộc tuân thủ test local.*
2. *Làm gọn các lượt gọi tool có 1 đối số chính thành dạng `toolName: mainParameter` và không cần escape quote `\"` trong backticks.*
3. *Loại bỏ tiền tố `Call tool `.*
4. *Thiết kế giao diện Responsive Mobile có thanh menu trượt (drawer sidebar).*
5. *Mặc định mở hết cây thư mục trong sidebar.*
6. *Tạo thanh điều hướng timeline `(1)--(2)--(3)...` đính trên Top-bar kết hợp Scrollspy đồng bộ URL Hash.*
7. *Sửa lỗi H2 tiêu đề User bị thanh topbar che mất khi scroll.*

### Việc đã làm
- **Định dạng Log sạch sẽ hơn**:
  - Viết kịch bản Python lọc bỏ tiền tố `Call tool` dư thừa.
  - Rút gọn tham số các lệnh `list_dir`, `view_file`, `write_to_file`, `run_command` về chỉ còn 1 tham số chính sau tên tool.
  - Loại bỏ các ký tự escape `\"` không cần thiết bên trong dấu backtick.
- **Tối ưu cây thư mục (File Tree)**:
  - Cho phép mở rộng (expanded) toàn bộ các thư mục con theo mặc định để người dùng dễ quan sát.
- **Responsive Mobile**:
  - Ẩn Sidebar trên màn hình di động, thay thế bằng nút Hamburger trượt mở Sidebar kết hợp backdrop mờ.
  - Ẩn badge loại file trên di động để giữ Topbar gọn gàng.
  - Tự động đóng Sidebar khi người dùng chọn xong tệp tin cần đọc.
- **Thanh tiến trình Timeline & Scrollspy**:
  - Tích hợp thanh timeline `(1)--(2)--(3)...` hiển thị ngay trên thanh Topbar.
  - Sử dụng phương thức `getBoundingClientRect()` để lấy chính xác vị trí tương đối của các tiêu đề `h2` trong khung cuộn, giải quyết triệt để lỗi tiêu đề bị Topbar đè che khuất.
  - Đồng bộ mượt mà Scrollspy đổi màu hạt active và thay đổi địa chỉ URL Hash (`#q1`, `#q2`...) tương ứng khi cuộn trang thủ công hoặc bấm nút timeline.
  - Tối ưu hóa hiệu năng bằng cách tính trước (pre-compute) tọa độ các thẻ tiêu đề để tránh gây giật lag (layout thrashing) khi cuộn.
